# PDF 中文字体

`wqy-microhei.ttc` 是未经修改的文泉驿微米黑字体，用于 PDF 中文字形嵌入与子集化。

来源：https://deb.debian.org/debian/pool/main/f/fonts-wqy-microhei/fonts-wqy-microhei_0.2.0-beta.orig.tar.gz

项目与版权信息：https://packages.debian.org/trixie/fonts-wqy-microhei

本项目按 Apache-2.0 许可分发该字体，完整许可与原作者信息见同目录的 `LICENSE_Apache2.txt`、`AUTHORS.txt`。无需安装系统字体或访问外部字体服务。
